What counts as a tier flip?
A between-turn flip means the previous turn ended on one model tier and the next began on another. A within-turn switch is shown separately, for example when the router escalates from Small to Strong. Date filters can include partial turns; counts follow the logged turn-starts.

Errors & unusual responses

HTTP statuses & measurement notes

Errors include HTTP status 400 or above and provider error events inside HTTP 200 responses. Other non-200 statuses are listed but are not necessarily errors. Missing header timings are excluded, not treated as zero. Headers can arrive before the model’s first token; true first-token timing is not available in this log. Median and p95 use nearest-rank percentiles. Small sample counts make comparisons noisy.
